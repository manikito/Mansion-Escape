## Overview
In this assignment, you will design and build a simple website using AI as a helper, not as a replacement for your thinking. 
Your job is to create a website that looks polished, works correctly, and shows your own ideas.
No coding experience is required, but you will learn some basic HTML, CSS, and JavaScript while completing this assignment, along with effective use of AI tools. 

You will use GitHub to store your work and track your progress, and you will submit your final project through CS++ Classroom.

## Assignment Task
Create a website about a topic you care about. Your website can be about a hobby, game, sport, artist, cause, school club, travel destination, or a fictional idea.

Your website should feel intentional, creative, and easy to use. It should not look like a plain default template.

### Your website must include:
- a clear topic and audience
- at least 3 sections or 3 pages
- a navigation menu
- original text written by you
- at least 2 images or visuals
- CSS styling with a consistent colour theme and readable fonts
- one interactive feature using JavaScript, such as a button, form, quiz, slider, gallery, or dark/light mode toggle
- website works on desktop
- a README file that explains the website and includes how you used AI to help you

## Rules for Using AI
AI is allowed in this assignment, but it must be used carefully.

You may use AI to:
- brainstorm website ideas
- generate general HTML, CSS, and/or JavaScript code snippets to help you learn about the features of web development.
- explain HTML, CSS, or JavaScript code
- help find bugs or fix errors
- suggest layout, colour, or design ideas
- help improve your writing

You may NOT use AI to:
- generate complete code solutions without understanding them
- submit AI-generated work without editing it
- use AI to complete the entire assignment for you
- use copyrighted images or text without permission
- use AI generated art/images

You must be able to explain your own website and the code you used.

### How to Commit and Push in VS Code
Use these steps every time you finish a small part of your project.

1. Save your files.
2. Open Source Control in VS Code:
	- Click the Source Control icon on the left sidebar (branch icon), or press `Ctrl+Shift+G`.
3. Review your changed files under "Changes".
4. Stage your files:
	- Click the `+` beside each file, or click `+` beside "Changes" to stage all.
5. Write a commit message at the top (short and clear), for example:
	- `added home page layout`
	- `fixed navbar links`
6. Click "Commit" (checkmark icon).
7. Push your commit to GitHub:
	- Click "Sync Changes" or "Push" when prompted.
8. Verify your commit on GitHub in your repository page.

If this is your first push from this folder, VS Code may ask you to "Publish Branch." Click it and choose your GitHub repository settings.

## How to Make It Work
Follow these steps in order.

### Step 1: Choose a topic
Pick something simple enough to finish, but interesting enough that you want to keep working on it.

Good ideas:
- a fan site for a game, movie, or sport
- a website for a school club or event
- a travel or city guide
- a personal hobby page
- a fictional brand or product site

Avoid projects that are too large, such as a full online store or a huge multi-page social network.

[Back to top](#top)

### Step 2: Plan the pages or sections
Before coding, sketch the site on paper or in a notebook. You will submit this on the deadline day.

Ask yourself:
- What is the purpose of the website?
- Who is the audience?
- What content belongs on each page?
- Where will the navigation go?

[Back to top](#top)

### Step 3: Build the HTML first
Start with the structure before adding fancy design. Use effective prompts and clear instructions with Copilot AI to help you build and learn about HTML. Make sure you understand the code you are using. 

Your HTML should include:
- a header
- navigation links
- main content
- images or cards
- a footer

Your main page of the website should be called `index.html`. Other pages can be named based on their content, such as `about.html` or `gallery.html`.

[Back to top](#top)

### Step 4: Add CSS styling
Make the website look designed, not default. Use effective prompts and clear instructions with Copilot AI to help you build and learn about CSS. Make sure you understand the code you are using.

Try to include:
- a colour palette with 2 to 4 main colours
- readable font choices
- spacing between sections
- hover effects on buttons or links
- a layout that still works on small screens

Name this file `styles.css` and link it to your HTML pages.

[Back to top](#top)

### Step 5: Add one JavaScript feature
Keep it simple and useful. Use effective prompts and clear instructions with Copilot AI to help you build and learn about JavaScript. Make sure you understand the code you are using.

Name this file `script.js` and link it to your HTML pages.

Examples:
- a button that changes text
- a form that responds to a submit event
- a photo gallery with next/previous buttons
- a quiz with instant feedback
- a theme toggle

[Back to top](#top)

### Step 6: Test and fix problems
Check your site for:
- broken links
- spelling mistakes
- images that do not load
- buttons that do nothing

[Back to top](#top)

### Step 7: Use GitHub properly
Save versions of your work as you go.

You should have multiple commits that show your progress from start to finish.
